## Context

Автономное приложение без внешних библиотек. Статический HTTP используется для загрузки ES-модулей при локальной разработке.

## Goals / Non-Goals

Цели: отрабатывать список, валидацию и расчёт прогресса. Состояние сбрасывается при перезагрузке, чтобы повторять сценарии на одинаковых данных.

## Decisions

- Задача хранится как { id, title, hours, done }. Начальное состояние создаётся заново при загрузке.
- domain.mjs экспортирует чистые функции общего контракта. Обновления возвращают массив, а вычисление метрик получает полный список.
- Сумма выполненных часов делится на общую сумму. При нуле используется 0, в остальных случаях Math.round(100 * done / total).
- Проверка формы выполняется до обновления массива. После ошибки поле сохраняется, сообщение связано с полем. Часы допускают точку или запятую в качестве десятичного разделителя.
- При каждом изменении статуса, фильтра или состава списка интерфейс обновляет задачи и общие метрики. Элементы задач создаются через DOM, название выводится как текст.
- На узком экране поля формы расположены вертикально, длинные названия переносятся.

## Risks / Trade-offs

При открытии модульных файлов по file:// браузер может блокировать импорт. Для запуска используется локальный статический HTTP-сервер. Потерю состояния при перезагрузке считаем допустимой для минимальной версии.
