## Why

Трекер нужен для планирования учебных задач на неделю и оценки выполнения по затраченным часам.

## What Changes

- Добавление, удаление и отметка готовности задачи.
- Фильтры «Все», «Активные» и «Готовые».
- Метрики по часам и проверка формы с подсказками у полей.
- Интерфейс для обычного браузера и узкого экрана.

## Capabilities

### New Capabilities

- `tracker`: ведение списка задач, проверка ввода и расчёт итогов недели.

### Modified Capabilities

Существующих возможностей нет.

## Impact

Новые HTML, CSS и два JavaScript-модуля. Состояние живёт до перезагрузки страницы. Аккаунты, синхронизация и постоянное хранение вне задачи.
