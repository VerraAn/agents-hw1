# Общий интерфейс для заранее подготовленных тестов

`initialTasks()` возвращает новый список. `validate(title, hours)` возвращает объект ошибок с ключами title и/или hours; пустой объект означает успех. Часы передаются строкой из формы. `addTask(tasks, title, hours)`, `removeTask(tasks, id)`, `toggleTask(tasks, id)` возвращают список; ошибка добавления сохраняет исходные задачи. `filterTasks(tasks, mode)` принимает all, active, done. `summarize(tasks)` возвращает { total, done, percent }; done здесь означает сумму часов, а не флаг задачи. Значения метрик считаются по полному списку.

Тесты и бриф скопированы побайтово в обе папки до появления кода.
